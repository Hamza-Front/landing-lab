# Restaurant — Café & Restaurant Landing Page

A modern, fully responsive landing page for a café or restaurant, built with
**HTML5**, **Tailwind CSS**, and **Vanilla JavaScript** — no frameworks, no build step.

[View Live Demo](https://hamza-front.github.io/landing-lab/restaurant/)

## ✨ Features
- Fully responsive layout (mobile, tablet, desktop)
- Sticky navbar with mobile hamburger menu (Vanilla JS)
- Hero section with background image and gradient overlay
- Menu section with category filter (Breakfast / Lunch / Dinner)
- Tabs for menu categories with smooth switching (JS)
- Gallery with lightbox viewer (Vanilla JS)
- Reservation form with real-time client-side validation
- Testimonials slider with autoplay and dots (Vanilla JS)
- Google Maps embed for location
- Smooth scroll navigation between sections
- Scroll reveal animations using Intersection Observer
- Dark mode toggle with `localStorage` persistence
- Semantic HTML5 and accessible markup (ARIA labels, keyboard navigation, focus states)

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS
- Vanilla JavaScript (ES6+)
- Google Fonts
- Remix Icons / Font Awesome
