# Progym — Gym & Fitness Landing Page

A modern, responsive landing page for a gym/fitness center, built with
HTML, Tailwind CSS, and Vanilla JavaScript.

## 🔗 Live Demo
[View Live](https://hamza-front.github.io/landing-lab/progym/)

## 📸 Preview
![Progym Preview](./assets/preview.png)

## ✨ Features
- Fully responsive layout (mobile, tablet, desktop)
- Sticky navbar with mobile hamburger menu (Vanilla JS)
- Hero section with call-to-action
- Services / Classes section with hover effects
- Trainers section with cards
- Pricing plans
- Contact form with client-side validation (no libraries)
- Smooth scroll navigation
- Scroll reveal animations (Intersection Observer)
- Dark mode toggle with localStorage
- Semantic HTML5 and accessible markup (ARIA, focus states)

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (CDN / CLI)
- Vanilla JavaScript (ES6+)
- Google Fonts
- Remix Icons / Font Awesome
